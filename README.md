## IA no SQL Server 2025: Construa Buscas Inteligentes Vetores, Embeddings e RAG


Repositório oficial com os scripts apresentados na palestra do **Prof. Landry Duailibe Salles Filho**.

---

**🗓️ 26/09/2026 – 15h | Sala 108**
Nesta palestra, vamos explorar como os novos recursos do SQL Server 2025 aproximam Inteligência Artificial e banco de dados, permitindo construir soluções de busca semântica, busca vetorial e RAG (Retrieval-Augmented Generation) sem abandonar o T-SQL e o conhecimento que o profissional de dados já possui.

A apresentação parte dos fundamentos de similaridade semântica, vetores e embeddings, mostrando como textos podem ser representados numericamente e utilizados para encontrar conteúdos com significados semelhantes, mesmo quando as palavras pesquisadas são diferentes.

Também veremos como funciona uma arquitetura de RAG, desde a preparação dos documentos, passando por chunking, geração de embeddings e armazenamento em uma base vetorial, até a busca dos trechos mais relevantes e sua utilização como contexto para uma LLM gerar a resposta.

A palestra inclui demonstrações práticas utilizando o tipo vector no SQL Server e a construção de um fluxo completo de RAG, além de abordar busca vetorial exata (ENN) e aproximada (ANN).

O objetivo é mostrar que o DBA e o desenvolvedor SQL não precisam começar do zero para trabalhar com IA.  É possível evoluir o T-SQL que já conhecem para criar aplicações capazes de pesquisar por significado e utilizar dados corporativos como contexto para modelos de Inteligência Artificial.
